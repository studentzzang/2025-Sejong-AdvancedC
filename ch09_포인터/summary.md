# 09 포인터 
### 9.1 포인터 개요, 주소 연산자

`포인터`: 메모리 주소를 나타내는 개념, 저장공간 가리킴

변수 선언될 때 할당되는 메모리 주소에 접근함<br>
구하는 법: `&` 주소연산자 변수앞에 붙인다 / 포인터 주소는 정수 <br>
`%d` (10진수) `%x` (16진수) / 주소출력 서식 `%p` = 16진수로 주소 출력

```
int a; // 정수 변수 선언
int *p; // 정수 포인터 변수 p선언
p = &a; // 변수 a의 주소 저장하는 변수를 다시 대입 (=포인터 변수 )
```

### 9.2 포인터 선언과 사용
`포인터 선언`: 참조연산자 `*`를 변수명 앞에 붙이기 (위 코드 처럼)
포인터 변수 선언 할 때 자료형 = 포인터 변수가 가리키는 것의 자료형

```
char *pch; // 일반적으로 이렇게 변수 앞에 씀

char* pch; //이 자료형뒤에 붙여도 됨
```
```
int num, *pnum = &num; //가능, 선언과 동시에 대입, 나중에 *pnum 출력할 때 주소 출력되는 건 아님
int *pnum = &num, num; // 컴파일 에러,  num 선언 전 사용됨
```
<br>

`포인터 연결`: 포인터 변수에 주소만 대입될 수 있음

- 포인터 값에도 쓰레기값 들어가니 꼭 초기화 (NULL로 초기화 ㄱㄴ)
- 주소연산자(&)는 포인터를 포함한 모든 변수에 사용 가능, 참조연산자(*)는 포인터 변수에만
- 포인터변수 자료형=연결된 변수 자료형, 다르면 에러

`포인터 크기`: sizeof(변수명) 찍어보면 모든 포인터 크기는 4바이트, double, char, long모두 4바이트

### 9.3 배열과 포인터
배열 요소 하나 하나 메모리 주소가 다르다. <br>
배열 자체 메모리 주소 = 인덱스0번 요소 메모리 주소 <br>
* &배열명 말고 그냥 배열명도 그 배열의 주소를 나타냄 즉, 출력 할 때 <br>
`ar = &ar = &ar[0]`
- 그러면 `*ar`은 인덱스 0번 '요소'
- `*(ar+1) = ar[1]`
- `배열명+n` = 인덱스n번 요소의 '주소', 출력할 때 `%p`
- 위에 처럼 선언 과 동시에 배열명 대입 가능

**다시 이해**: *은 선언할 때 빼고 그 주소를 가진 변수의 값에 접근하는 것

ex)
```
int ar[5] = {2,3,5,7,-1}
int *p = ar; // ar[0]의 메모리 주소
printf("%p %d\n", p,*p);
printf("p %d\n", p+1, *(p+1));
```
실행결과
```
001E40B4 2
pp1E40B8 3
```
**주의**: 참조 연산자(*)는 산술 연산자 보다 먼저 여서 위 코드에서 *p+3을 하면 ar[0] + 3 이나 마찬가지임.
그래서 괄호 꼭

- 반대로 배열이 대입된 포인터를 배열처럼 사용 가능
```mermaid
int ar[3] = {3,7,5};
int *p =ar;
printf("%d\n", p[1]); // 7 출력
```

**정리** <br>
```mermaid
int ar[5], *p = ar;

i번째 원소의 주소: &ar[i] = ar+i = p+i = &p[i]
i번재 원소의 값: ar[i] = *(ar+i) = *(p+i) = p[i]
```
**포인터 배열 - 인덱스**

포인터에 배열의 중간 요소의 주소를 넣어도 됨. 인덱스 0 아닌것.
```mermaid
int ar[5] = {2,3,5,7,-1}
int *p = &ar[2]; // ar 인덱스2 값의 주소 들어감

printf("%p %d\n", p-2, p[-2]);
printf("%p %d", p, p[0]);
```
- 이 때 p의 인덱스 0번 기준이 ar[2]기준이 된다. 그래서 범위만 안 넘는다면 음수
인덱스와 주소 접근도 가능하다.

### 9.4 포인터 연산
포인터 연산에 +,- 뿐 아니라 ++와 --, +=, -=도 가능<br>
예를 들어 ++p는 p[1]의 주소값<br>
*(p++) 는 p[1]의 요소값 출력
