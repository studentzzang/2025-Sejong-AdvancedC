# 09 포인터 
### 9.1 포인터 개요, 주소 연산자

`포인터`: 메모리 주소를 나타내는 개념, 저장공간 가리킴

변수 선언될 때 할당되는 메모리 주소에 접근함<br>
구하는 법: `&` 주소연산자 변수앞에 붙인다 / 포인터 주소는 정수 <br>
`%d` (10진수) `%x` (16진수) / 주소출력 서식 `%p` = 16진수로 주소 출력

```
int a; // 정수 변수 선언
int *p; // 정수 포인터 변수 p선언
p = &a; // 변수 a의 주소 저장하는 변수를 다시 대입 (=포인터 변수 )
```

### 9.2 포인터 선언과 사용
`포인터 선언`: 참조연산자 `*`를 변수명 앞에 붙이기 (위 코드 처럼)
포인터 변수 선언 할 때 자료형 = 포인터 변수가 가리키는 것의 자료형

```
char *pch; // 일반적으로 이렇게 변수 앞에 씀

char* pch; //이 자료형뒤에 붙여도 됨
```
```
int num, *pnum = &num; //가능, 선언과 동시에 대입, 나중에 *pnum 출력할 때 주소 출력되는 건 아님
int *pnum = &num, num; // 컴파일 에러,  num 선언 전 사용됨
```
<br>

`포인터 연결`: 포인터 변수에 주소만 대입될 수 있음

- 포인터 값에도 쓰레기값 들어가니 꼭 초기화 (NULL로 초기화 ㄱㄴ)
- 주소연산자(&)는 포인터를 포함한 모든 변수에 사용 가능, 참조연산자(*)는 포인터 변수에만
- 포인터변수 자료형=연결된 변수 자료형, 다르면 에러

`포인터 크기`: sizeof(변수명) 찍어보면 모든 포인터 크기는 4바이트, double, char, long모두 4바이트

### 9.3 배열과 포인터
배열 요소 하나 하나 메모리 주소가 다르다. <br>
배열 자체 메모리 주소 = 인덱스0번 요소 메모리 주소 <br>
* &배열명 말고 그냥 배열명도 그 배열의 주소를 나타냄 즉, 출력 할 때 <br>
`ar = &ar = &ar[0]`
- 그러면 `*ar`은 인덱스 0번 '요소'
- `*(ar+1) = ar[1]`
- `배열명+n` = 인덱스n번 요소의 '주소', 출력할 때 `%p`
- 위에 처럼 선언 과 동시에 배열명 대입 가능

**다시 이해**: *은 선언할 때 빼고 그 주소를 가진 변수의 값에 접근하는 것

ex)
```
int ar[5] = {2,3,5,7,-1}
int *p = ar; // ar[0]의 메모리 주소
printf("%p %d\n", p,*p);
printf("p %d\n", p+1, *(p+1));
```
실행결과
```
001E40B4 2
pp1E40B8 3
```
**주의**: 참조 연산자(*)는 산술 연산자 보다 먼저 여서 위 코드에서 *p+3을 하면 ar[0] + 3 이나 마찬가지임.
그래서 괄호 꼭

- 반대로 배열이 대입된 포인터를 배열처럼 사용 가능
```
int ar[3] = {3,7,5};
int *p =ar;
printf("%d\n", p[1]); // 7 출력
```

**정리** <br>
```
int ar[5], *p = ar;

i번째 원소의 주소: &ar[i] = ar+i = p+i = &p[i]
i번재 원소의 값: ar[i] = *(ar+i) = *(p+i) = p[i]
```
**포인터 배열 - 인덱스**

포인터에 배열의 중간 요소의 주소를 넣어도 됨. 인덱스 0 아닌것.
```
int ar[5] = {2,3,5,7,-1}
int *p = &ar[2]; // ar 인덱스2 값의 주소 들어감

printf("%p %d\n", p-2, p[-2]);
printf("%p %d", p, p[0]);
```
- 이 때 p의 인덱스 0번 기준이 ar[2]기준이 된다. 그래서 범위만 안 넘는다면 음수
인덱스와 주소 접근도 가능하다.

### 9.4 포인터 연산
포인터 연산에 +,- 뿐 아니라 ++와 --, +=, -=도 가능<br>
예를 들어 ++p는 p[1]의 주소값<br>
*(p++) 는 p[1]의 요소값 출력

ex)
```
int ar[5] = {1,2,3,4,5};

int i;
int *p=ar;

for (i=0; i<5; i++) {
    printf("ar[%d] = %d\n", i, *p++); // 이렇게 가능
}

return 0;
```

** 주소 비교 **
주소는 비교연산자 `(==, !=, < >) 등` 사용하여 비교 가능

ex)
```
int ar[3] = {2,3,5}, *p1 = &ar[1], *p2 = &ar[2];
printf("%d\n", p1 < p2);
printf("%d\n", p1 > p2);
```
출력결과
```
1
0
```
- 주소 끼리 정수 더하기 빼기만 가능 하며 실수 연산, 곱하기, 나누기는 안 된다.(컴파일 에러)

### 9.5 포인터 인자와 주소 변환

**포인터 인자**
함수 매개변수가 포인터 변수 (int *p)면 인수는 &a 이런식

```
#include <stdio.h>

void change(int *p);

int main() {

    int a = 5;

    change(&a);

    printf("a = %d", a);

    return 0;
}

void change(int *p){
    *p=100;
}
```
출력결과
```
a = 100
```
** ?이렇게 쓰는 이유**
보통 int, float같은 매개변수를 넣는 것을 `값에 의한 호출` 이라고 함. <br>
위처럼 주소를 전달하는 것을 `주소에 의한 호출`<br>
`주소에 의한 호출`은 다른 함수에서 변수의 값에 영향을 줄 수 있음. <br>

만약 위 코드에서 포인터가 매개변수가 아닌 그냥 int값이 매개변수 였다면

```
#include <stdio.h>

void change(int p);

int main() {

    int a = 5;

    change(a);

    printf("a = %d", a);

    return 0;
}

void change(int p){
    p=100;
}
```
출력결과
```
a = 5
```

아래 코드는 어떨까?
```
#include <stdio.h>

void change(int *p);

int main() {

    int a = 3;
    int *pa = &a;

    change(pa);

    printf("a = %d", a);

    return 0;
}

void change(int *p){
    *p=10;
}
```
출력결과
```
a = 10
```
***포인터에 대입되는 것은 하나의 값이 아닌 그저 주소를 가리키는 주소 번지를 저장 할 뿐
이라고 이해하면 편할 것 같다.***

- scanf() 함수에 값을 전달할 때 주소연산자(&)를 붙이는 이유가 값 자체를 바꾸기 위해서임.
- printf() 에 일반적으로 값만 전달하지만 주소를 출력하려면 주소연산자(&)를 붙어야됨.

**주소 반환 함수+연습예제**
- 주소 반환 함수는 선언할때 int *p(매개변수) ... 이런식으로 해주면 된다.
* 두 정수 변수의 주소를 받아 '값'이 작은 변수의 '주소 반환'하는 smaller 함수를 작성
```
#include <stdio.h>

int *smaller(int *p1, int *p2);

int main(){

    int ar[3] = {1,3,-4};

    int *big1 = smaller(ar, ar+1);
    int *big2 = smaller(ar, ar+2);
    printf("%p / %d\n", big1, *big1);
    printf("%p / %d", big2, *big2);

    return 0;
}

int *smaller(int *p1, int *p2){
    if(*p1 > *p2){
        return p1;
    }
    else{
        return p2;
    }
}
```
출력결과
```
0x7ffc74200570 / 3
0x7ffc7420056c / 1
```
* smaller함수에서 삼항연산자로 한줄에 하려 했는데 에러남
